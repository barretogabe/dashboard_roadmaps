# Busca Global Clínica Reativa e Sinalização de Auditoria de Dados

Decidimos estruturar a busca da plataforma como uma busca reativa full-text de múltiplos atributos clínicos (pesquisando simultaneamente por condição, sintomas secundários, comorbidades, alvos anatômicos 10-20 como M1, F3, F4 e termos de observações).

Adicionalmente, os protocolos e roadmaps originários do acervo 2025–2026 que possuam pendências metodológicas documentadas (como TEPT transcrito via OCR preliminar ou magnitudes ainda não reportadas) receberão uma sinalização visual explícita com selo de advertência: *"⚠️ Em revisão pelo GT Temático — dados preliminares do ciclo 2025–2026"*. Isso assegura transparência científica sem privar o GT de um ambiente 100% funcional para testes durante o desenvolvimento.
